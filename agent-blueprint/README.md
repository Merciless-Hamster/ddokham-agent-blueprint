# 에이전트 설계도 (agent-blueprint)

내 업무를 AI에게 맡기고 싶은데 무엇부터 만들어야 할지 모를 때, 그리고 이미 만든 에이전트를 정리하고 싶을 때 쓰는 플러그인입니다.

**똑햄 에이전트 규칙**에 맞춰 설계합니다.

- 새로 만들 때 — 내 업무에 맞는 것이 무엇인지 판정하고, 그것을 만들기 위한 문서 세 개를 만들어 줍니다.
- 기존 에이전트를 고칠 때 — 지금 에이전트를 진단하고, 고칠 것마다 보완 문서를 만들어 줍니다.

모든 업무에 에이전트가 필요한 것은 아닙니다.
자료 하나로 문서 하나 만드는 일에 에이전트를 세우면 관리할 것만 늘어납니다.
이 플러그인은 답변을 보고 세 갈래 중 하나를 골라 주고, 왜 그렇게 판단했는지 이유를 함께 보여 줍니다.

| 갈래 | 만드는 것 | 어디서 쓰나 |
|------|----------|-----------|
| 스킬 | 스킬 하나 | 계정에 올려 두고 어디서든 |
| 도구 | 버튼 화면이 있는 도구 | 내 PC, 필요하면 동료에게 |
| 에이전트 | 똑햄 규칙에 맞춘 메인 파일·서브 에이전트·스킬·폴더 | Claude Code |

## 쓰는 법

만들고 싶은 결과물 파일이 들어 있는 폴더, 또는 고치고 싶은 에이전트 폴더를 Claude Code로 엽니다.
그리고 `/ddokham-blueprint`를 칩니다. 그게 전부입니다.

처음에 두 가지를 묻습니다.

1. 새로 만들까요, 기존 에이전트를 보완할까요?
2. 똑햄 에이전트 규칙을 반영할까요? 반영하지 않으면 여기서 마칩니다.

그다음은 상황에 맞는 질문만 이어집니다. 폴더에서 알 수 있는 것은 묻지 않고 초안으로 보여 줍니다.
파일이 없어도 됩니다. 준비된 예시 네 가지 중에서 고르면 됩니다.

## 똑햄 에이전트 규칙

일을 수행하는 에이전트를 위한 규칙입니다. 웹이나 앱을 만드는 바이브코딩용 에이전트에는 쓰지 않습니다.

- 업무 프로젝트마다 폴더를 따로 두고, 폴더마다 현황 파일 하나로 진행 상황을 봅니다.
- 자주 보는 파일은 한 폴더에 모으고 파일마다 요약을 붙여, 요약을 먼저 보고 필요한 원본만 엽니다.
- 메인 파일은 목적과 길 안내만 맡고, 실제 일은 서브 에이전트와 스킬이 나눠 맡습니다.
- 에이전트를 고칠 때는 보완 기록 폴더에서 보완 문서와 변경 이력으로 관리합니다.

폴더와 파일 이름은 고정하지 않습니다. 이미 쓰는 이름을 따르거나, 업무에 맞게 제안해서 고칠 수 있게 합니다.

## 커맨드 두 개

| 커맨드 | 하는 일 |
|--------|--------|
| `/ddokham-blueprint` | 새로 만들 때는 판정과 문서 세 개를, 고칠 때는 진단과 보완 문서를 만들어 줍니다 |
| `/ddokham-blueprint-redraw` | 기획서를 고친 뒤 나머지 둘을 다시 만듭니다 |

`/ddo`까지만 쳐도 둘 다 목록에 뜹니다.

## 새로 만들 때 만들어지는 파일 세 개

폴더 안에 `설계도` 폴더가 하나 생기고 그 안에 들어갑니다.

| 파일 | 무엇인가 |
|------|---------|
| `기획서.md` | 사람이 읽고 직접 고치는 문서입니다. 여기가 원본입니다 |
| `설계도.html` | 전체 흐름과 구성을 한 장 그림으로 본 것입니다. 더블클릭하면 브라우저에서 열립니다 |
| `세팅_프롬프트.md` | 실제로 만들 때 그대로 붙여 넣을 프롬프트입니다 |

설계도를 보다가 고칠 곳이 보이면 `기획서.md`를 고치고 `/ddokham-blueprint-redraw`를 치면 됩니다.
인터뷰를 처음부터 다시 하지 않아도 됩니다.

## 기존 에이전트를 고칠 때 만들어지는 것

진단표를 보고 고칠 것을 고르면, 고칠 것마다 보완 문서가 하나씩 생기고 추적표에 한 줄씩 올라갑니다.
보완 기록 폴더가 없으면 보완 절차·변경 이력·추적표·보완 문서 틀로 된 골격도 함께 만듭니다.
보완 문서 맨 끝의 문장을 새 세션에 붙여 넣으면 그 계획대로 고치기 시작합니다.

## 이 플러그인이 하지 않는 것

**설계만 합니다. 아무것도 초기화하지 않고, 에이전트를 직접 고치지 않습니다.**

메인 파일도, 서브 에이전트도, 스킬도, 작업 폴더도 만들거나 고치지 않습니다.
새로 생기는 것은 `설계도` 폴더와 그 안의 파일 세 개, 또는 보완 기록 폴더 안의 보완 문서뿐입니다.

실제로 만들고 고치는 일은 다음 단계이고, 그때 `세팅_프롬프트.md`나 보완 문서를 쓰면 됩니다.

## 설치하는 법

### 방법 1 — 마켓플레이스에서 설치 (권장)

1. Claude Code를 엽니다.
2. `/plugin marketplace add Merciless-Hamster/ddokham-agent-blueprint`를 입력합니다.
3. `/plugin install agent-blueprint@ddokham`을 입력합니다.
4. `/ddo`를 쳐서 커맨드 두 개가 뜨면 설치된 것입니다.

### 방법 2 — 폴더 복사

네트워크가 막혀 있거나 설치가 안 될 때 쓰는 방법입니다.

1. `agent-blueprint` 폴더를 받습니다.
2. 그 안의 `commands` 폴더와 `skills` 폴더를, 작업할 폴더 안의 `.claude` 폴더에 복사해 넣습니다. `.claude` 폴더가 없으면 만듭니다.
3. Claude Code를 다시 엽니다.
4. `/ddo`를 쳐서 커맨드 두 개가 뜨면 된 것입니다.
